# 사용 가이드

EMG 팔찌와 앱으로 손동작을 녹화하고, 사용자에게 맞춘 모델을 학습시켜, 손동작을
실시간으로 인식하는 방법입니다. 설치가 끝났다는 전제로 설명합니다(설치는 [INSTALLATION_GUIDE.md](INSTALLATION_GUIDE.md)).

---

## 1. 어떻게 동작하나요

팔찌의 센서 8개가 팔 근육의 전기 신호를 읽습니다. 손동작마다 예시를 몇 번 녹화하면
앱이 그 사람에게 맞춘 모델을 학습시키고, 그 뒤로 팔찌가 손동작을 실시간으로 알아봅니다.
모델은 **사람마다 따로** 만듭니다.

인식하는 손동작:

| 이름 | 동작 |
|---|---|
| rest | 힘 빼고 쉬기 |
| flexion | 손목 굽히기 |
| extension | 손목 펴기 |
| close | 주먹 쥐기 |
| supination | 손바닥을 위로 돌리기 |
| pronation | 손바닥을 아래로 돌리기 |

---

## 2. 시작하기 전에

**준비물**

- ESP32-S3 EMG 팔찌
- 앱이 설치된 PC
- PC의 블루투스 켜기
- 처음 한 번은 USB 케이블 (펌웨어 설치용)

**팔찌 착용** — 위치가 나쁘면 인식도 나빠집니다.

- 아래팔, 팔꿈치에서 **손가락 3개 너비만큼 아래**
- 표시가 **위쪽, 손바닥 쪽**을 향하게
- 미끄러지지 않게 **꼭 맞게**
- 피부는 깨끗하고 마른 상태로

착용 사진은 앱 첫 화면에도 나옵니다.

---

## 3. 앱 실행

앱 폴더에서 PowerShell을 열고 실행합니다.

```powershell
.venv\Scripts\python.exe client_app\main.py
```

앱 창과 함께 터미널 창이 열려 있습니다. 터미널에는 1초마다 `[BLE] 1150 Hz | 57.5 pkt/s`
같은 수신 상태가 찍힙니다. **이 줄이 멈추면 팔찌 신호가 끊긴 것**입니다.

---

## 4. 단계별 사용법

앱 위쪽의 Phase 순서대로 진행합니다.

| 단계 | 할 일 |
|---|---|
| **0 Firmware** | USB로 팔찌를 연결하고 **Install capture firmware**를 누릅니다. 1~2분 기다립니다. 이미 설치된 팔찌는 **Skip**으로 넘어갑니다. |
| **1 Capture** | ① 피험자 정보를 입력합니다. ② **캘리브레이션:** 5초 동안 팔에 힘을 빼고 가만히 있습니다. 앱이 쉬고 있을 때의 신호를 기준값으로 잽니다. ③ **녹화:** **Start recording**을 누르고 화면에 나오는 손동작(움직이는 시연 포함)을 따라 합니다. |
| **2 Training** | **Create my model**을 누르면 녹화한 데이터로 모델을 학습합니다. |
| **3 Install** | 학습한 모델을 팔찌에 넣습니다. 처음에는 USB(**Install on bracelet**), 그다음부터는 **Send weights over BLE**로 무선 전송하면 됩니다. |
| **4 Verify** | 모델이 제대로 들어갔는지 확인합니다. |
| **5 Score** | 팔찌가 손동작을 실시간으로 인식합니다. |

### 녹화 한 번(take)의 진행

```
쉬기 5초 → 손동작 10초 → 쉬기 5초 → 손동작 10초 → ...
```

- **쉬기(pause):** 팔에 힘을 빼고 기다립니다.
- **손동작:** 화면에 나온 동작을 10초 동안 흔들림 없이 유지합니다.
- 화면 지시가 바뀌는 순간 동작도 바로 바꿔 주세요. 그 시점을 기준으로 정답(라벨)이 붙습니다.
- 녹화 전에는 왼쪽 화면이 비어 있는 것이 정상입니다. **Start recording**을 누르면 동작 이름과 시연이 나옵니다.

## 5. 화면 경고와 대처

| 경고 | 뜻 | 할 일 |
|---|---|---|
| **Sensor contact: Not connected: CH…** | 해당 채널 전극이 피부에 제대로 닿지 않음 | 팔찌를 다시 꼭 맞게 차고, 경고가 사라진 뒤 녹화 |
| **Noise detected / Heavy noise (saturation)** | 신호가 측정 범위 끝(0 또는 255)에 붙는 일이 많음 | 팔찌를 다시 차고 팔에 힘을 뺀 상태에서 경고가 사라지는지 확인 |
| **Heavy noise (high noise at rest)** | 쉬는 구간인데 신호가 큼 | 쉬는 동안 팔에 완전히 힘을 빼기, 전극 접촉 확인 |
| **electrode contact** (녹화 확인 화면) | 녹화 중 센서 하나가 제대로 닿지 않았음 | 다시 차고 그 녹화를 다시 하기 |
| **weak signal / old firmware** | 팔찌에 오래된 펌웨어가 들어 있음 | Phase 0에서 **Install capture firmware**로 다시 설치 |

빨간 경고가 뜬 채로 녹화한 데이터는 모델 정확도를 떨어뜨립니다. **SEE PREVIOUS TAKES**에서
확인하고 문제가 있는 녹화는 다시 하세요.

## 6. 자주 묻는 질문

**팔찌가 목록에 안 나와요 ("Choose bracelet"이 비어 있음)**
- PC 블루투스가 켜져 있는지 확인하세요.
- 팔찌 LED가 보라색으로 계속 깜빡이면 내부 센서를 찾지 못해 부팅이 안 끝난 상태입니다. 전원을 껐다 켜고, 계속되면 배선을 점검해야 합니다.
- 다른 프로그램(다른 PC, 휴대폰 앱)이 이미 연결 중일 수 있습니다. 팔찌를 껐다 켜 보세요.

**녹화 중 터미널의 `[BLE]` 줄이 멈췄어요**
- 팔찌 신호가 끊긴 것입니다. 앱은 끊겨도 녹화 순서를 계속 진행하므로, 그 녹화는 버리고 다시 하세요.
- 팔찌를 PC 가까이 두고, 몸으로 팔찌와 PC 사이를 가리지 않게 하세요.

**`[BLE]` 줄의 숫자가 1200보다 많이 낮아요 (예: 900 Hz)**
- 블루투스 수신이 약한 상태입니다. 거리를 줄이고, 근처의 무선 기기(Wi-Fi 공유기, 블루투스 이어폰)를 멀리 두세요.

**실시간 인식이 잘 안 돼요**
- 착용 위치와 피부 접촉을 다시 확인하세요. 녹화할 때와 다르게 차면 정확도가 떨어집니다.
- 그래도 안 되면 깨끗한 신호로 다시 녹화하고 학습하세요.

**특정 동작이 자꾸 다른 동작으로 인식돼요**
- 그 동작을 다른 동작과 확실히 구분되게, 더 분명하게 다시 녹화하세요.

**"Send weights over BLE"에서 `Characteristic ... was not found` 오류가 나요**
- 팔찌에 예전 펌웨어가 들어 있습니다. Phase 3의 USB 설치("Install on bracelet")를 먼저 한 번 하세요.
